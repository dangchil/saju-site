# 사주 노트

휴대폰 앱처럼 쓰는 사주 사이트의 1단계 뼈대입니다.
HTML, CSS, 자바스크립트만으로 만들었고, 설치나 빌드 없이 GitHub Pages에서 그대로 열립니다.
풀이 문장은 아직 비어 있고, 사주 원리를 공부하면서 `data/` 폴더의 파일에 하나씩 채워 넣게 되어 있습니다.

## 풀이 내용 채우는 법

풀이 글은 모두 `data/` 폴더 안의 파일에 들어 있습니다. 메모장으로 열어 고치면 됩니다.
GitHub 웹사이트에서 파일을 열고 연필 모양 단추를 눌러 바로 고쳐도 됩니다.

### 파일과 화면의 관계

| 파일 | 들어 있는 것 | 화면에서 나오는 곳 |
|---|---|---|
| `data/ilgan.json` | 일간 10개 (갑~계) | 만세력 › '나의 일간' 칸, 오늘의 일진 › '내 일간' 칸 |
| `data/sipsung.json` | 십성 10개 (비견~정인) | 만세력 › '원국에 있는 십성' 칸 (원국에 나온 십성만) |
| `data/jiji.json` | 지지 12개 (자~해) | 만세력 › '원국의 지지' 칸 (년지·월지·일지·시지) |
| `data/iljin.json` | 오늘이 나에게 어떤 십성인 날인지 10개 | 오늘의 일진 › '오늘이 나에게 ○○인 날' 칸 |
| `data/ilju.json` | 육십갑자 일주 60개 (갑자~계해) | 오늘의 일진 › 맨 위 '오늘의 일주' 칸 |
| `data/site.json` | 홈 소개 한 문단 | 홈 › 굵은 안내 문장 아래 '이곳은' 칸 |

### 한 항목은 이렇게 생겼습니다

`data/ilgan.json` 을 열면 이런 덩어리가 열 개 있습니다.

```
  "갑": {
    "설명": "갑목(甲木) 일간, 양의 목. 일간이 갑인 사람에게 나옵니다. ...",
    "내용": "준비 중"
  },
```

- `"갑"` 은 이름표입니다. 화면이 이 이름표로 항목을 찾으니 **바꾸지 마세요.**
- `"설명"` 은 이 항목이 무엇이고 화면 어디에 나오는지 적어 둔 메모입니다. 화면에는 나오지 않습니다.
- `"내용"` 의 따옴표 안 글이 화면에 나옵니다. **여기만 고치면 됩니다.**

예를 들어 갑목 일간 풀이를 쓰려면 `"준비 중"` 을 이렇게 바꿉니다.

```
    "내용": "여기에 갑목 일간 풀이를 씁니다."
```

저장하고 GitHub에 올리면 1~2분 뒤 사이트에 반영됩니다.
일간이 갑인 사람이 만세력을 보면 '나의 일간' 칸에 이 글이 또렷하게 나옵니다.

### 흐린 칸은 아직 안 채운 곳입니다

`"내용"` 이 `"준비 중"` 이거나 비어 있으면 그 칸은 화면에서 흐리게 보이고,
제목 옆에 어느 파일을 고치면 되는지(예: `data/ilgan.json`)가 작게 붙습니다.
사이트를 둘러보다 흐린 칸이 보이면 그 파일을 열어 채우면 됩니다.

### 지켜야 할 규칙 몇 가지

이 파일들은 JSON이라는 형식이라, 아래 규칙을 어기면 그 파일 전체를 읽지 못합니다.
(그때는 화면의 해당 칸이 모두 "준비 중"처럼 흐리게 나옵니다. 사이트가 멈추지는 않습니다.)

1. 글은 반드시 큰따옴표 `" "` 안에 씁니다.
2. 글 안에서 큰따옴표를 쓰고 싶으면 `\"` 처럼 앞에 `\` 를 붙이거나, 작은따옴표 `' '` 나 「 」 를 쓰세요.
3. 줄을 바꾸려면 엔터 대신 `\n` 을 씁니다. 예: `"첫 줄입니다.\n둘째 줄입니다."`
4. 항목과 항목 사이의 쉼표 `,` 는 지우지 마세요. 마지막 항목 뒤에는 쉼표가 없습니다.
5. 고친 뒤 형식이 맞는지 걱정되면 jsonlint.com 같은 곳에 파일 내용을 붙여 넣어 확인할 수 있습니다.

### 그 밖에 고칠 수 있는 곳

- 사이트 이름: `js/common.js` 의 `SITE_NAME` 한 줄, 그리고 각 html 파일의 `<title>`
- 이용약관·개인정보처리방침·사업자 정보: `legal.html` 의 "준비 중" 세 곳
- 캐릭터 그림: `index.html`, `chat.html`, `my.html` 의 `char-slot` 빈 원 자리
- 색: `css/style.css` 맨 위 `:root` 안의 값

## 사주 공부 글 올리는 법

`study/posts/` 폴더에 `.md` 파일 하나를 넣으면 글 페이지가 생기고 목록에도 자동으로 올라갑니다.

1. `study/posts/_글_틀.md` 를 복사해 같은 폴더에 새 이름으로 저장합니다.
   이름은 `_` 없이, 순서대로 놓이도록 숫자로 시작하면 좋습니다. 예: `01-음양.md`
2. 첫 줄 `# ` 뒤에 제목을 씁니다. 이 제목이 목록에 나옵니다.
3. 본문을 쓰고 GitHub에 올립니다.

목록은 파일 이름 순서로 놓입니다. 글이 세 편보다 적으면 남은 자리는 빈 칸으로 보입니다.
이 기능은 GitHub Pages가 `.md` 파일을 웹 페이지로 바꿔 주는 기능(Jekyll)을 씁니다.
그래서 내 컴퓨터에서 파일을 바로 열면 목록이 비어 보이고, GitHub Pages에 올리면 제대로 보입니다.
