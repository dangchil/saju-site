# 사주 노트

휴대폰 앱처럼 쓰는 사주 사이트입니다. 밝고 귀여운 화면에 캐릭터가 안내하는 모양으로 되어 있습니다.
HTML, CSS, 자바스크립트만으로 만들었고, 설치나 빌드 없이 GitHub Pages에서 그대로 열립니다.
풀이 문장은 아직 비어 있고, 사주 원리를 공부하면서 `data/` 폴더의 파일에 하나씩 채워 넣게 되어 있습니다.

## 화면 구성

화면 아래에 탭 네 개(홈, 일진, 상담, 사주 공부)가 있고, 내 정보는 홈 오른쪽 위 사람 모양 단추로 들어갑니다.

| 파일 | 화면 |
|---|---|
| `index.html` | 홈. 오늘의 일주 인사, 만세력·일진·상담·해설·공부 입구, 만든 사람 소개, 자주 묻는 질문 |
| `manse.html` | 만세력. 원국(사령 강조), 오행 분포, 대운과 세운(대운을 누르면 세운이 바뀝니다) |
| `iljin.html` | 오늘의 일진. 오늘의 간지, 오늘이 내 일간에게 어떤 십성인지, 이번 주 일진 |
| `chat.html` | 상담 화면 미리보기 (아직 작동하지 않습니다) |
| `report.html` | 평생 사주 해설 미리보기 (1장만 보입니다) |
| `study/index.html` | 사주 공부 글 목록 |
| `my.html` | 내 정보 (준비 중) |
| `legal.html` | 이용약관, 개인정보처리방침, 사업자 정보 (준비 중) |

만세력에서 넣은 생일은 이 기기의 브라우저에만 저장되고(서버로 보내지 않습니다), 일진과 해설 화면이 그 생일을 이어서 씁니다.

## 풀이 내용 채우는 법

풀이 글은 모두 `data/` 폴더 안의 파일에 들어 있습니다. 메모장으로 열어 고치면 됩니다.
GitHub 웹사이트에서 파일을 열고 연필 모양 단추를 눌러 바로 고쳐도 됩니다.

### 파일과 화면의 관계

| 파일 | 들어 있는 것 | 화면에서 나오는 곳 |
|---|---|---|
| `data/ilgan.json` | 일간 10개 (갑~계) | 만세력 › 아래쪽 '○ 일간 이야기' 카드 |
| `data/sipsung.json` | 십성 10개 (비견~정인) | 만세력 › '원국에 있는 십성' 칸 (원국에 나온 십성만) |
| `data/jiji.json` | 지지 12개 (자~해) | 만세력 › '원국의 지지' 칸 (년지·월지·일지·시지) |
| `data/iljin.json` | 오늘이 나에게 어떤 십성인 날인지 10개 | 오늘의 일진 › '오늘이 나에게 ○○인 날' 칸 |
| `data/ilju.json` | 육십갑자 일주 60개 (갑자~계해) | 오늘의 일진 › 맨 위 연보라 카드의 아래 칸 |
| `data/report.json` | 1장 '타고난 기질' 10개 (일간 갑~계) | 평생 사주 해설 › '1장 미리보기' 카드 |
| `data/faq.json` | 자주 묻는 질문 3개 (질문과 답) | 홈 › 맨 아래 '자주 묻는 질문' (질문은 접힌 상자 제목, 답은 펼친 안쪽) |
| `data/site.json` | 만든 사람 이름·소속·사진·소개, 유튜브 주소, 캐릭터 이름 | 홈 › '누가 만들었나요?' 카드, 상담 › 맨 위 '○○과 이야기' |

### 한 항목은 이렇게 생겼습니다

`data/ilgan.json` 을 열면 이런 덩어리가 열 개 있습니다.

```
  "갑": {
    "설명": "갑목(甲木) 일간, 양의 목. 일간이 갑인 사람에게 나옵니다. ...",
    "내용": "준비 중"
  },
```

- `"갑"` 은 이름표입니다. 화면이 이 이름표로 항목을 찾으니 **바꾸지 마세요.**
- `"설명"` 은 이 항목이 무엇이고 화면 어디에 나오는지 적어 둔 메모입니다. 화면에는 나오지 않습니다.
- `"내용"` 의 따옴표 안 글이 화면에 나옵니다. **여기만 고치면 됩니다.**

예를 들어 갑목 일간 풀이를 쓰려면 `"준비 중"` 을 이렇게 바꿉니다.

```
    "내용": "여기에 갑목 일간 풀이를 씁니다."
```

저장하고 GitHub에 올리면 1~2분 뒤 사이트에 반영됩니다.
일간이 갑인 사람이 만세력을 보면 '갑 일간 이야기' 카드에 이 글이 또렷하게 나옵니다.

### 흐린 칸은 아직 안 채운 곳입니다

`"내용"` 이 `"준비 중"` 이거나 비어 있으면 그 칸은 화면에서 흐리게 보이고,
제목 옆에 어느 파일을 고치면 되는지(예: `data/ilgan.json`)가 작게 붙습니다.
사이트를 둘러보다 흐린 칸이 보이면 그 파일을 열어 채우면 됩니다.

### data/faq.json — 자주 묻는 질문

항목마다 `"질문"` 과 `"내용"` 두 칸이 있습니다. `"질문"` 은 홈 맨 아래 접힌 상자의 제목으로,
`"내용"` 은 상자를 눌러 펼쳤을 때 보이는 답으로 나옵니다. 질문 문장을 바꾸고 싶으면 `"질문"` 을 고치면 됩니다.

```
  "질문1": {
    "설명": "첫 번째 질문. ...",
    "질문": "태어난 시간을 몰라도 볼 수 있나요?",
    "내용": "여기에 답을 씁니다."
  },
```

### data/report.json — 평생 사주 해설 1장

평생 사주 해설 화면의 '1장 미리보기'에 나오는 '타고난 기질' 풀이입니다. 일간마다 하나씩 열 개가 있고,
저장된 생일의 일간에 맞는 항목 하나가 화면에 나옵니다. 예를 들어 `"경"` 항목을 채우면
일간이 경금인 사람이 해설 화면을 열었을 때 그 글이 보입니다.

### data/site.json — 만든 사람 소개와 이름들

| 이름표 | 화면에서 나오는 곳 | 적는 법 |
|---|---|---|
| `만든이_이름` | 홈 '누가 만들었나요?' 카드의 이름 | 예: `"홍길동 교수"` |
| `만든이_소속` | 이름 아래 작은 글씨 | 예: `"○○대학교 ○○학과"` |
| `만든이_사진` | 동그란 사진 자리 | 사진 파일을 `images/` 폴더에 올린 뒤 경로를 적습니다. 예: `"images/profile.jpg"` |
| `만든이_소개` | 이름 아래 소개 문장 | 지금 들어 있는 문장을 고쳐 써도 됩니다 |
| `유튜브_주소` | '유튜브 채널 보기' 단추 | 채널 주소 전체를 적습니다. 예: `"https://www.youtube.com/@채널이름"` |
| `캐릭터_이름` | 상담 화면 맨 위 '○○과 이야기' | 예: `"새싹이"` (받침에 맞춰 '과/와'가 저절로 바뀝니다) |

`"준비 중"` 으로 두면 이름 자리는 `[교수님 이름]` 처럼 흐리게, 사진은 점선 원으로 보이고,
유튜브 단추는 눌리지 않게 됩니다.

### 캐릭터 그림 바꾸는 법

모든 화면의 캐릭터는 `images/mascot.svg` 파일 하나를 함께 씁니다.
새 그림을 같은 이름 `mascot.svg` 로 저장해 이 파일을 바꿔 넣으면 모든 화면의 캐릭터가 한꺼번에 바뀝니다.
GitHub 웹사이트에서는 `images` 폴더를 열고 'Add file → Upload files' 로 같은 이름의 파일을 올리면 됩니다.

- 그림은 정사각형이 가장 잘 맞습니다. 동그란 얼굴이 가운데 오도록 그려 주세요.
- PNG 그림을 쓰고 싶으면 `images/mascot.png` 로 올린 뒤, `js/common.js` 의 `MASCOT` 한 줄에서
  `mascot.svg` 를 `mascot.png` 로 바꾸세요. (브라우저 탭에 뜨는 작은 아이콘은 각 html 의 `<link rel="icon">` 줄에서 바꿉니다)

### 지켜야 할 규칙 몇 가지

이 파일들은 JSON이라는 형식이라, 아래 규칙을 어기면 그 파일 전체를 읽지 못합니다.
(그때는 화면의 해당 칸이 모두 "준비 중"처럼 흐리게 나옵니다. 사이트가 멈추지는 않습니다.)

1. 글은 반드시 큰따옴표 `" "` 안에 씁니다.
2. 글 안에서 큰따옴표를 쓰고 싶으면 `\"` 처럼 앞에 `\` 를 붙이거나, 작은따옴표 `' '` 나 「 」 를 쓰세요.
3. 줄을 바꾸려면 엔터 대신 `\n` 을 씁니다. 예: `"첫 줄입니다.\n둘째 줄입니다."`
4. 항목과 항목 사이의 쉼표 `,` 는 지우지 마세요. 마지막 항목 뒤에는 쉼표가 없습니다.
5. 고친 뒤 형식이 맞는지 걱정되면 jsonlint.com 같은 곳에 파일 내용을 붙여 넣어 확인할 수 있습니다.

### 그 밖에 고칠 수 있는 곳

- 사이트 이름: `js/common.js` 의 `SITE_NAME` 한 줄, 그리고 각 html 파일의 `<title>`
- 이용약관·개인정보처리방침·사업자 정보: `legal.html` 의 "준비 중" 세 곳
- 색과 글꼴: `css/style.css` 맨 위 `:root` 안의 값 (오행 칩 색도 여기 있습니다)
- 사주 공부 글 네 편(천간이란, 지지란, 오행, 십성이란): `study/posts/01-ganji.md`, `01-jiji.md`, `02-ohaeng.md`, `03-sipsung.md`. 홈의 '사주 공부' 카드가 이 네 글로 이어집니다. 글을 더하거나 빼면 `index.html` 의 '7. 사주 공부' 카드도 함께 고치세요
- `css/style.css` 나 `js/` 파일을 고친 뒤에는 각 html 에서 그 파일을 부르는 줄 끝의 `?v=20261004` 숫자를 새로 바꿔 주세요(예: 고친 날짜). 숫자가 바뀌어야 방문자 브라우저가 예전 파일 대신 새 파일을 받습니다

## 사주 공부 글 올리는 법

`study/posts/` 폴더에 `.md` 파일 하나를 넣으면 글 페이지가 생기고 목록에도 자동으로 올라갑니다.

1. `study/posts/_글_틀.md` 를 복사해 같은 폴더에 새 이름으로 저장합니다.
   이름은 `_` 없이, 순서대로 놓이도록 숫자로 시작하면 좋습니다. 예: `01-음양.md`
2. 첫 줄 `# ` 뒤에 제목을 씁니다. 이 제목이 목록에 나옵니다.
3. 본문을 쓰고 GitHub에 올립니다.

목록은 파일 이름 순서로 놓입니다. 글이 세 편보다 적으면 남은 자리는 빈 칸으로 보입니다.
본문이 "준비 중" 한 줄뿐인 글은 흐리게 보입니다.
이 기능은 GitHub Pages가 `.md` 파일을 웹 페이지로 바꿔 주는 기능(Jekyll)을 씁니다.
그래서 내 컴퓨터에서 파일을 바로 열면 목록이 비어 보이고, GitHub Pages에 올리면 제대로 보입니다.

## 계산 엔진

- `js/manse.js` : 만세력 계산 엔진. `dangchil/manseryeok` 의 `index.html` 안 계산 부분을
  한 글자도 바꾸지 않고 옮겨 왔습니다. 모든 페이지가 이 파일을 불러 씁니다.
- `js/saju-extra.js` : 원본에 없는 계산 (사령 지장간, 오늘 날짜, 일주). `manse.js` 를 건드리지 않으려고 따로 두었습니다.
  사령은 흔히 쓰는 월률분야 날수 표(예: 인월 무7·병7·갑16일)를 썼고, 학파에 따라 다른 표를 쓰려면 `SARYEONG_DAYS` 의 숫자만 바꾸면 됩니다.
- `js/common.js` : 아래 탭, 맨 아래 안내, data 파일 읽기, 캐릭터 그림 경로, 선 아이콘처럼 모든 페이지가 함께 쓰는 화면 부품.

## 내 컴퓨터에서 미리 보기

파일을 더블클릭해서 열면 브라우저 보안 규칙 때문에 `data/` 파일을 읽지 못해 풀이 칸이 모두 흐리게 나옵니다.
폴더에서 `python3 -m http.server` 를 실행한 뒤 `http://localhost:8000` 으로 열면 제대로 보입니다.
